# 忆时光视频生成业务实现方案

## 一、需求概述

在忆时光项目的Medusa底部模型上增加用户生成视频业务，实现以下功能：
- 产品支持"生成视频"和"普通产品"两种类型
- 为生成视频产品配置可替换素材（图片、声音、背景、视频）
- 用户选择产品后可替换素材，生成视频
- 扣除积分，形成订单，记录生成结果
- 在"我的回忆"中展示生成的视频

## 二、数据库设计

### 2.1 产品类型扩展

在Medusa v2中，需要扩展Product模型的metadata字段：

```typescript
// Product metadata 新增字段
{
  product_type: "normal" | "video_generation",  // 产品类型
  video_config?: {
    template_id: string,  // 视频模板ID
    duration: number,     // 视频时长（秒）
  }
}
```

### 2.2 可替换素材表（新建模块）

创建新的Medusa模块：`video-material`

**表名**: `video_material`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | string | 主键 |
| product_id | string | 关联产品ID |
| name | string | 素材名称（如：角色1、背景音乐） |
| material_key | string | 素材标识（用于替换时的key） |
| material_type | enum | 素材类型：image/audio/background/video |
| default_url | string | 默认素材URL |
| is_replaceable | boolean | 是否可替换 |
| sort_order | number | 排序 |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

**示例数据**:
```json
{
  "id": "mat_01",
  "product_id": "prod_video_01",
  "name": "角色1",
  "material_key": "character_1",
  "material_type": "image",
  "default_url": "/assets/sister.pic",
  "is_replaceable": true,
  "sort_order": 1
}
```

### 2.3 用户生成视频表（新建模块）

创建新的Medusa模块：`user-video`

**表名**: `user_video`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | string | 主键 |
| user_id | string | 用户ID |
| order_id | string | 关联订单ID |
| product_id | string | 使用的产品ID |
| video_url | string | 生成的视频URL |
| thumbnail_url | string | 视频缩略图URL |
| title | string | 视频标题 |
| duration | number | 视频时长（秒） |
| status | enum | 状态：pending/processing/completed/failed |
| materials_used | json | 使用的素材配置 |
| error_message | string | 错误信息（如果失败） |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

**materials_used 字段示例**:
```json
{
  "character_1": {
    "original_url": "/assets/sister.pic",
    "replaced_url": "/uploads/user_123/photo_1.jpg",
    "type": "image"
  },
  "background_music": {

    "replaced_url": null,
    "type": "audio"
  }
}
```

import { MedusaRequest, MedusaResponse } from "@medusajs/framework/http"
import { VIDEO_MATERIAL_MODULE } from "../../../../../modules/video-material"

export async function GET(
  req: MedusaRequest,
  res: MedusaResponse
) {
  const videoMaterialService = req.scope.resolve(VIDEO_MATERIAL_MODULE)
  const productId = req.params.id

  const materials = await videoMaterialService.listVideoMaterials({
    product_id: productId,
  }, {
    order: { sort_order: "ASC" }
  })

  res.json({ materials })
}

## 八、注意事项

1. **性能优化**: 视频生成是耗时操作，需要使用异步处理和队列
2. **错误处理**: 需要完善的错误处理和重试机制
3. **存储管理**: 视频文件较大，需要考虑存储成本和CDN加速
4. **安全性**: 文件上传需要验证文件类型和大小
5. **用户体验**: 提供实时进度反馈和通知功能
