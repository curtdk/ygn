# 数据库迁移说明

## 自动迁移

Medusa v2 使用 MikroORM 进行数据库管理，模块定义的模型会自动生成迁移文件。

### 生成迁移

```bash
cd medushaV2
npm run build
npx medusa db:generate
```

这将根据模型定义自动生成迁移文件。

### 运行迁移

```bash
npx medusa db:migrate
```

## 手动SQL（如果需要）

如果自动迁移有问题，可以手动执行以下SQL：

### 创建 video_material 表

```sql
CREATE TABLE IF NOT EXISTS video_material (
  id VARCHAR(255) PRIMARY KEY,
  product_id VARCHAR(255) NOT NULL,
  name VARCHAR(255) NOT NULL,
  material_key VARCHAR(255) NOT NULL,
  material_type VARCHAR(50) NOT NULL CHECK (material_type IN ('image', 'audio', 'background', 'video')),
  default_url TEXT NOT NULL,
  is_replaceable BOOLEAN DEFAULT TRUE,
  sort_order INTEGER DEFAULT 0,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_product_id (product_id),
  INDEX idx_material_key (material_key)
);
```

### 创建 user_video 表

```sql
CREATE TABLE IF NOT EXISTS user_video (
  id VARCHAR(255) PRIMARY KEY,
  user_id VARCHAR(255) NOT NULL,
  order_id VARCHAR(255),
  product_id VARCHAR(255) NOT NULL,
  video_url TEXT,
  thumbnail_url TEXT,
  title VARCHAR(255) NOT NULL,
  duration INTEGER DEFAULT 0,
  status VARCHAR(50) DEFAULT 'pending' CHECK (status IN ('pending', 'processing', 'completed', 'failed')),
  materials_used JSON,
  error_message TEXT,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_user_id (user_id),
  INDEX idx_status (status),
  INDEX idx_created_at (created_at)
);
```

## 验证迁移

运行迁移后，验证表是否创建成功：

```sql
-- 检查表是否存在
SHOW TABLES LIKE 'video_%';

-- 查看表结构
DESCRIBE video_material;
DESCRIBE user_video;
```

## 回滚迁移

如果需要回滚：

```bash
npx medusa db:migrate:down
```

或手动删除表：

```sql
DROP TABLE IF EXISTS user_video;
DROP TABLE IF EXISTS video_material;
```
