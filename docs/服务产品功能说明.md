# 服务产品功能说明

## 功能概述

服务产品模块为商家提供一个展示和销售专业服务的平台，包括：

- **服务产品展示**：浏览可用的专业服务
- **服务订单管理**：查看和管理已购买的服务订单
- **服务商订单**：服务商可查看和管理的服务订单

## 访问方式

### 1. 导航栏入口（已添加）
在顶部导航栏添加了"服务"链接，点击即可访问服务页面：
- 首页导航 → 服务

### 2. 直接访问 URL
```
http://localhost:8000/cn/service
http://localhost:8000/us/service
http://localhost:8000/dk/service
```

### 3. 后台管理 (Admin)
- **本地开发**: http://localhost:9000/app
- **生产环境**: https://ygn.tatagogo.com/app

## 详细操作步骤

### 第一步：在后台创建服务产品

#### 1. 登录后台管理系统
```
1. 访问 http://localhost:9000/app
2. 使用管理员账户登录（首次使用需要初始化设置）
```

#### 2. 创建产品类型（可选）
```
1. 进入 Settings → Product Types
2. 点击 "Create product type"
3. 填写类型信息：
   - Value: "Service" 或 "服务"
4. 保存
```

#### 3. 创建服务产品
```
1. 进入 Products 模块
2. 点击 "Create new product"
3. 填写产品信息：
   - Title: 产品标题（如"专业视频制作"）
   - Type: 选择 "Service" 或留空
   - Status: Published
4. 在 General 标签页设置价格：
   - 点击 Variants → Add variant
   - 设置价格（如 299.00 CNY）
5. 在 Options 标签页添加选项（如有需要）
6. 在 Media 标签页上传产品图片
7. 保存产品
```

#### 4. 标记为服务产品（推荐方式）
```
1. 在编辑产品页面
2. 找到 Metadata 字段
3. 添加元数据：
   - Key: is_service
   - Value: true
4. 保存
```

### 第二步：查看前台服务页面

#### 1. 访问服务页面
```
1. 点击导航栏"服务"链接
2. 或直接访问 http://localhost:8000/cn/service
```

#### 2. 服务页面包含三个 Tab
- **Service Products** - 查看所有服务产品
- **My Orders** - 查看我的服务订单（需登录）
- **Provider Orders** - 服务商查看订单（需登录）

### 第三步：购买服务

```
1. 在服务产品列表点击产品卡片
2. 查看产品详情和价格
3. 点击"Add to Cart"添加到购物车
4. 进入购物车结算
5. 完成支付
```

### 第四步：管理服务订单

#### 作为客户
```
1. 登录账户
2. 进入"服务"页面
3. 点击"My Orders"标签
4. 查看订单状态和历史
```

#### 作为服务商
```
1. 登录服务商账户
2. 进入"服务"页面
3. 点击"Provider Orders"标签
4. 查看和处理客户的服务订单
```

## API 接口说明

### 获取服务产品列表
```
GET /store/service-products
Response: { service_products: [], count: 0 }
```

### 获取服务订单
```
GET /store/service-orders
Headers: Authorization: Bearer <token>
Response: { service_orders: [], count: 0 }
```

### 获取服务商订单
```
GET /store/service-orders/provider
Headers: Authorization: Bearer <token>
Response: { provider_orders: [], count: 0 }
```

## 故障排除

### 问题：访问 /service 页面显示 404
**解决方法**：检查 middleware.ts 中的 region 配置，确保 region 包含当前国家代码

### 问题：服务产品列表为空
**解决方法**：确认产品已在后台创建，且状态为 Published

### 问题：无法访问 Admin 后台
**解决方法**：检查 MEDUSA_ADMIN_ONBOARDING_TYPE 配置
