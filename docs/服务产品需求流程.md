美杜莎系统新增上门服务模块开发需求（最终完整版）
 
整体开发前提：
基于现有美杜莎商城系统完整复制一套独立程序、前端页面、后台功能、数据库结构，拆分出服务产品独立体系；原有实物商城所有功能、数据、流程完全保留不动，两套体系互不干扰，共用同一套用户账号体系。
 
1. 用户身份规则
 
1. 共三类角色：消费用户、平台管理员、服务人员
2. 普通用户可在手机端个人中心申请成为服务人员
3. 申请需提交：手机号、身份证正反面、工作证件、荣誉证书
4. 提交后由平台后台人工审核，审核通过才解锁服务人员全部权限
 
2. 产品类型区分
 
新增产品类型字段，区分两种商品逻辑
 
1. 普通实物商品：沿用系统原有下单、交易、结算流程，不作改动
2. 服务类产品：走本次定制上门服务专属订单流程
 
3. 服务产品完整业务流程
 
1. 平台后台发布服务类产品，发布时提前预设：服务人员佣金比例、三级推荐分润比例
2. 消费用户正常选购服务产品，下单并完成支付
3. 订单同步至平台后台，后台支持修改订单地址等信息
4. 订单审核：后台配置开关，支持自动审核/人工审核两种模式，审核通过订单才进入抢单池
5. 仅已认证服务人员可查看抢单订单列表，根据自身条件自主抢单
6. 订单派单：后台配置开关，支持自动派单/人工派单；自动则抢单直接生效，人工可平台指派接单人员
7. 服务人员抵达现场后，上传现场合照凭证，点击开启服务
8. 服务完成后，服务人员手动提交结束订单
9. 订单收尾：用户可手动确认结束，未操作则按后台设定时长自动完结；完结后用户对订单做1-5星星级评价，复用系统原有评价功能
10. 佣金结算：后台开关控制自动结算/平台审核后结算，按预设佣金自动划转费用给服务人员
11. 多级分润：后台单独分润操作按钮，支持手动执行分润；包含下单用户推荐链、服务人员推荐链三级分润，各层级分润可单独开关控制
 
4. 新增分润台账相关功能
 
1. 数据库新增分润信息数据表，存储所有分润明细数据
2. 移动端个人中心新增分润记录页面，所有获得分润的用户均可查看
3. 分润记录展示字段：对应来源订单编号、分润金额、收支变动、分润来源用户、上下级推荐关系链路
4. 后台增设订单收入、资金流水统计页面，汇总全部分润与佣金数据
5. 佣金流水、分润明细仅服务人员权限可见
 
5. 前后端页面与权限要求
 
手机前端
 
1. 普通用户：浏览服务产品、下单付款、查看个人订单、订单结束后评价
2. 服务人员专属页面：订单抢单页、自身服务订单进度页、服务启停操作、图片凭证上传、个人佣金与分润明细查询
3. 个人中心：固定放置服务人员入驻申请入口、分润记录入口
 
平台管理后台
 
1. 独立服务产品发布、编辑管理模块
2. 订单管理：订单信息修改、订单审核、抢单记录查看、人工指派订单
3. 资质审核：审核用户服务人员入驻资料
4. 全局参数配置：审核模式、派单模式、订单自动结束时长、佣金比例、三级分润比例、结算模式开关
5. 资金操作：佣金结算、手动多级分润发放、订单资金流水查询
 
6. 核心配置开关汇总
 
全部开关统一放在后台配置处，可随时切换
 
1. 订单审核：自动审核 / 人工审核
2. 订单派单：自动确认接单 / 平台人工指派
3. 费用结算：自动结算佣金 / 后台审核结算佣金
4. 各级三级分润：单独开启、关闭权限
5. 订单自动完结时长自定义设置
 
7. 数据与架构要求
 
1. 原商城代码、页面、数据库原样保留运行
2. 复刻全套系统生成独立服务模块，单独开发新增抢单、派单、资质审核、凭证上传、多级分润、分润台账功能
3. 全平台共用用户账号，身份升级不影响原有账户数据、资产信息
 
8. 开发模式与自动化测试要求
 
1. 整体项目分阶段分步开发，不可一次性全部编写完成
2. 每一个开发阶段完工后，必须先使用自研测试工具完成基础功能自测
3. 基础自测通过后，再使用Playwright工具开展自动化流程测试
4. 当前阶段所有测试全部校验合格无问题后，才可自动进入下一阶段开发工作
5. 全程按阶段开发、阶段自测、自动化校验、阶段放行的节奏推进项目
