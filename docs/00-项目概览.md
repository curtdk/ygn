# 项目概览

## 忆光年 (YGN) - 电商 + AI视频生成平台

### 技术栈

| 层级 | 技术 | 版本 |
|------|------|------|
| 后端框架 | Medusa | 2.13.1 |
| 前端框架 | Next.js | 15.x |
| 数据库 | PostgreSQL | - |
| 缓存 | Redis | - |
| 搜索引擎 | Meilisearch | 1.35 |
| 对象存储 | 阿里云OSS | - |
| 支付 | 支付宝 | - |
| AI服务 | 阿里云视频人脸 | - |

### 服务端口

| 服务 | 地址 | 说明 |
|------|------|------|
| 后端API | http://localhost:9000 | Medusa API |
| Admin后台 | http://localhost:9000/app | 管理界面 |
| 前端 | http://localhost:8000 | Next.js storefront |
| Meilisearch | http://localhost:7700 | 搜索服务 |
| Redis | redis://localhost:6379 | 缓存 |

### 快速启动

```bash
# 1. 启动 Meilisearch (可选)
./scripts/start-meilisearch.sh

# 2. 启动后端
cd medushaV2 && npm run dev

# 3. 启动前端
cd medushaV2-storefront && yarn dev
```
