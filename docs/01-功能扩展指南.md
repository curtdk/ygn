# 功能扩展指南

## 如何扩展忆光年功能

### 扩展原则

1. **模块化开发** - 每个功能独立模块
2. **前后端分离** - API路由 + 前端组件
3. **配置驱动** - 使用环境变量配置
4. **测试覆盖** - 新功能必须有测试

---

## 后端扩展 (medushaV2/)

### 添加新模块

```
src/modules/your-feature/
├── index.ts          # 模块定义
├── service.ts        # 业务逻辑
├── models/           # 数据模型
│   └── your-model.ts
└── migrations/       # 数据库迁移
    └── Migration*.ts
```

### 添加API路由

```
src/api/store/your-route/
└── route.ts          # GET/POST/PUT/DELETE
```

### 添加Service服务

```
src/services/
├── your-service.ts   # 业务服务
└── external-api.ts   # 外部API调用
```

### 示例：添加新服务

```typescript
// src/services/your-service.ts
import { MedusaService } from "@medusajs/framework/utils"
import { Module } from "@medusajs/framework"

export class YourService extends MedusaService({}) {
  async yourMethod(data: any) {
    // 业务逻辑
    return result
  }
}
```

## 前端扩展 (medushaV2-storefront/)

### 添加新页面

```
src/modules/your-feature/
├── components/       # 组件
│   ├── your-card.tsx
│   └── your-form.tsx
└── templates/        # 页面模板
    └── your-page.tsx
```

### 添加新路由

在 `src/app/` 下按 Next.js App Router 规范创建：

```
src/app/[countryCode]/your-page/
├── page.tsx          # 页面组件
└── loading.tsx       # 加载状态
```

### Server Action 示例

```typescript
// src/lib/data/your-action.ts
"use server"

import { sdk } from "@lib/config"
import { revalidateTag } from "next/cache"

export async function yourAction(data: YourData) {
  try {
    const result = await sdk.client.fetch("/store/your-endpoint", {
      method: "POST",
      body: data
    })
    revalidateTag("your-cache-tag")
    return { success: true, data: result }
  } catch (error) {
    return { success: false, error: error.message }
  }
}
```

## 新增第三方集成

### 1. 添加环境变量

```bash
# .env
THIRD_PARTY_API_KEY=xxx
THIRD_PARTY_API_SECRET=xxx
THIRD_PARTY_WEBHOOK_URL=https://your-domain.com/webhooks/third-party
```

### 2. 创建Service封装

```typescript
// src/services/third-party.ts
export class ThirdPartyService {
  private apiKey: string
  
  constructor() {
    this.apiKey = process.env.THIRD_PARTY_API_KEY
  }
  
  async callAPI(endpoint: string, data: any) {
    // API调用逻辑
  }
}
```

### 3. 添加WebHook处理

```typescript
// src/api/webhooks/third-party/route.ts
export async function POST(req: Request) {
  // Webhook处理逻辑
}
```

## 工作流程 (Workflows)

### 创建新工作流

```
src/workflows/your-workflow/
├── index.ts
├── steps/
│   ├── step1.ts
│   └── step2.ts
└── handlers/
    └── handler.ts
```

### 示例工作流

```typescript
// src/workflows/generate-video/index.ts
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { step1 } from "./steps/step1"
import { step2 } from "./steps/step2"

export const generateVideoWorkflow = createWorkflow(
  "generate-video",
  function (input) {
    const result1 = step1(input)
    const result2 = step2(result1)
    return result2
  }
)
```

## 扩展清单

| 功能点 | 后端位置 | 前端位置 | 注意事项 |
|--------|----------|----------|----------|
| 新数据模型 | `modules/*/models/` | - | 需要创建迁移 |
| 新API | `api/store/` | SDK调用 | 注意版本控制 |
| 新页面 | - | `modules/*/templates/` | SEO优化 |
| 新组件 | - | `modules/*/components/` | 响应式设计 |
| 新服务 | `services/` | Server Actions | 错误处理 |
| 新工作流 | `workflows/` | - | 事务一致性 |
