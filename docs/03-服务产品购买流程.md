# 服务产品购买流程

本文档介绍服务产品（Service Products）购买流程的功能和实现。

## 概述

服务产品购买流程是一个独立于普通电商产品的购买系统，专门用于数字服务类产品的购买和交付。该流程包含产品展示、结算和支付确认三个主要环节。

## 状态管理

### 结算流程状态

1. **地址步骤** (`step=address`)
   - 填写收货地址
   - 填写联系方式（邮箱、电话）

2. **配送步骤** (`step=shipping`)
   - 选择配送方式
   - 支持到店自取

3. **支付步骤** (`step=payment`)
   - 选择支付方式
   - 输入支付信息

4. **确认步骤** (`step=review`)
   - 确认订单信息
   - 应用折扣码
   - 提交订单

## API 端点

### 后端 API

```
POST /store/carts/:id/line-items          # 添加商品到购物车
POST /store/carts/:id/shipping-methods     # 设置配送方式
POST /store/payment-collections/:id/sessions  # 创建支付会话
POST /store/carts/:id/complete             # 完成订单
```

### 前端 Server Actions

```typescript
// src/lib/data/cart.ts
addToCart()           # 添加到购物车
updateCart()          # 更新购物车
deleteLineItem()      # 删除商品
setShippingMethod()   # 设置配送方式
applyPromotions()     # 应用促销码
placeOrder()          # 提交订单
```

## 样式和设计

### Tailwind CSS 类

- 容器: `content-container`
- 布局: `flex flex-col`, `small:flex-row`
- 间距: `py-6`, `gap-y-6`, `gap-y-12`
- 边框: `border-ui-border-base`
- 按钮: `shadow-buttons-inverted`, `bg-ui-button-inverted`

### 设计原则

1. **响应式设计**: 支持移动端和桌面端
2. **表单友好**: 清晰的标签和输入框
3. **状态反馈**: 加载状态和错误提示
4. **一致性**: 与主站设计风格保持一致

## 扩展指南

### 添加新的配送方式

1. 在 Medusa Admin 创建配送选项
2. 关联到适当的 shipping profile
3. 在 `Shipping` 组件中显示新选项

### 添加新的支付提供商

1. 在 `src/modules/service/components/payment-button/index.tsx` 添加 case
2. 实现支付处理逻辑
3. 添加对应的支付 UI

### 添加新字段到地址表单

1. 修改 `shipping-address/index.tsx` 添加输入框
2. 确保后端 API 支持该字段
3. 在结算流程中正确处理
