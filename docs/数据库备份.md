# 数据库备份功能说明

## 概述

本项目添加了数据库备份功能，用于将 `ygn` 数据库备份至项目根目录的 `soldata` 文件夹下。

## 备份目录

所有的数据库备份文件将统一保存在以下路径：
`/www/wwwroot/nextjs/ygn/soldata/`

## 备份命令

我们可以使用 PostgreSQL 提供的 `pg_dump` 命令进行备份。执行以下命令即可将数据库备份到指定文件夹中：

```bash
# 创建备份目录（如果不存在）
mkdir -p /www/wwwroot/nextjs/ygn/soldata

# 执行备份命令（以时间戳命名文件）
pg_dump postgres://postgres@localhost/ygn > /www/wwwroot/nextjs/ygn/soldata/ygn_backup_$(date +%Y%m%d_%H%M%S).sql
```

**连接说明：**
- **用户**: `postgres`
- **主机**: `localhost`
- **数据库名**: `ygn`
- **生成文件**: 形如 `ygn_backup_20260325_102115.sql`

## 注意事项

- 请确保系统中已安装 PostgreSQL 客户端工具，并且有权限执行 `pg_dump` 命令。
- 定期清理 `soldata` 文件夹下较旧的备份文件，以防止磁盘空间占满。
