# 测试指南

## 当前测试设施

### 后端测试 (Medusa)

```bash
cd medushaV2

# 运行所有单元测试
npm run test:unit

# 运行集成测试 (HTTP)
npm run test:integration:http

# 运行单个测试文件
TEST_TYPE=unit NODE_OPTIONS=--experimental-vm-modules jest path/to/test.spec.ts --silent --runInBand --forceExit

# 运行单个测试 (按名称)
TEST_TYPE=unit NODE_OPTIONS=--experimental-vm-modules jest -t "test name pattern" --silent --runInBand --forceExit
```

## Playwright 测试

### 安装 Playwright

```bash
# 全局安装 (已有)
npx playwright --version  # Version 1.58.2

# 在项目中安装
cd medushaV2-storefront
npm install -D @playwright/test
npx playwright install chromium
```

### 创建 Playwright 测试

```typescript
// e2e/example.spec.ts
import { test, expect } from '@playwright/test';

test.describe('Homepage', () => {
  test('should load homepage correctly', async ({ page }) => {
    await page.goto('http://localhost:8000/dk');
    
    // 检查页面标题
    await expect(page).toHaveTitle(/忆光年/);
    
    // 检查导航存在
    await expect(page.locator('[data-testid="nav-store-link"]')).toBeVisible();
    
    // 检查产品分类
    await expect(page.locator('text=Shop by Category')).toBeVisible();
  });

  test('should navigate to products', async ({ page }) => {
    await page.goto('http://localhost:8000/dk');
    await page.click('text=商城');
    await expect(page).toHaveURL(/\/store/);
  });
});
```

### Playwright 配置

```typescript
// playwright.config.ts
import { defineConfig, devices } from '@playwright/test';

export default defineConfig({
  testDir: './e2e',
  fullyParallel: true,
  forbidOnly: !!process.env.CI,
  retries: process.env.CI ? 2 : 0,
  workers: process.env.CI ? 1 : undefined,
  reporter: 'html',
  use: {
    baseURL: 'http://localhost:8000',
    trace: 'on-first-retry',
  },
  projects: [
    {
      name: 'chromium',
      use: { ...devices['Desktop Chrome'] },
    },
  ],
});
```

### 运行 Playwright

```bash
# 运行所有测试
npx playwright test

# 运行特定文件
npx playwright test e2e/homepage.spec.ts

# 交互模式
npx playwright test --ui

# 调试模式
npx playwright test --debug
```

### 可用的 data-testid 选择器

前端组件已添加测试ID，方便定位：

| 元素 | data-testid |
|------|--------------|
| 导航Logo | `nav-store-link` |
| 账户链接 | `nav-account-link` |
| 购物车链接 | `nav-cart-link` |
| 产品列表 | `products-list` |
| 产品标题 | `product-title` |
| 价格 | `price` |
| 添加购物车按钮 | `add-product-button` |
| 登录表单 | `login-page` |
| 注册表单 | `register-page` |
| 搜索框 | `search-input` |

### 示例：测试购物车

```typescript
test('should add product to cart', async ({ page }) => {
  await page.goto('http://localhost:8000/dk/products/test-product');
  
  // 选择变体
  await page.click('[data-testid="option-button"]:has-text("Large")');
  
  // 添加到购物车
  await page.click('[data-testid="add-product-button"]');
  
  // 检查购物车数量
  await expect(page.locator('[data-testid="nav-cart-link"]')).toContainText('Cart (1)');
});
```
