核心功能模块：
=====================================

1. 素材管理 (video-material)
   - 存储产品的可替换素材配置
   - 支持图片、声音、背景、视频等类型
   - 管理默认素材和替换规则

2. 用户视频 (user-video)
   - 记录用户生成的视频
   - 跟踪生成状态
   - 存储视频URL和素材配置

3. API路由
   - Store API：供前端调用
   - Admin API：供后台管理使用

4. Admin Widget
   - 在产品详情页管理素材
   - 可视化配置界面

5. 工作流
   - 视频生成流程编排
   - 异步任务处理

数据流：
=====================================

后台配置流程：
Admin → 创建产品 → 配置素材 → video_material表

用户生成流程：
前端 → 选择产品 → 获取素材 → 替换素材 → 提交生成
     → 创建订单 → 扣除积分 → user_video表 → 触发工作流
     → 生成视频 → 更新状态 → 通知用户

查看视频流程：
前端 → 我的回忆 → 获取视频列表 → user_video表 → 显示视频

API调用关系：
=====================================

前端页面 → Store API → 模块服务 → 数据库
  ↓
Home.tsx → GET /store/products
  ↓
ConfigureRole.tsx → GET /store/products/{id}/materials
                  → POST /store/video-generation
  ↓
GenerateVideo.tsx → GET /store/my-videos/{id}
  ↓
Memories.tsx → GET /store/my-videos

后台管理 → Admin API → 模块服务 → 数据库
  ↓
Admin UI → GET/POST/DELETE /admin/video-materials
